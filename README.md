# 🚀 Git & GitHub Learning Repository

📚 A repository created for learning, practicing, and testing Git & GitHub.

## 📌 About

This repository is created for learning and testing purposes.
The main goal is to understand and practice Git commands, GitHub workflows, and branching concepts through hands-on experimentation.

## 📚 What I'm Learning

- 🔧 Basic Git commands
- 📁 Creating and managing repositories
- 💾 Creating and managing commits
- 🌿 Creating and working with branches
- 🔀 Merging branches
- 🗑️ Deleting branches
- ⚔️ Handling merge conflicts
- 🐙 Working with GitHub remote repositories
- 📤 Pushing changes to GitHub
- 📥 Pulling changes from GitHub
- 🔄 Understanding Git workflows

## 🌿 Branching Practice

This repository is also used to practice different branching concepts.

```text
main
│
├── feature-1
│
├── feature-2
│
└── testing
```

Branches may be created, modified, merged, and deleted while experimenting with Git.

## 🧪 Repository Purpose

This is a learning and practice repository.
The files, commits, and branches may be:

- Experimental
- Incomplete
- Frequently modified

The purpose is to learn by doing and gain a better understanding of Git and GitHub.
